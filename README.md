# bango-virtual-storage

A virtual storage app inspired by the Bāngo design. Manage your files and images through a clean virtual-storage interface.

## ✨ Features

- **Virtual Storage** - Organize and manage your files in one place
- **Image Management** - Upload and manage images with ease
- **Customizable Limits** - Set your own storage limits and quotas
- **Bāngo-inspired UI** - Clean, modern design language

## 🚀 Getting Started

Clone the repository and run the app locally:

```bash
git clone https://github.com/hashes030692-beep/bango-virtual-storage.git
cd bango-virtual-storage
# Open the app in your browser
```
